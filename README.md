Aplicación educativa interactiva para el aprendizaje de **Tópicos de Matemáticas**, desarrollada bajo la norma **NTE-UAN-APK-001 v1.3** de la **Universidad Autónoma de Nayarit**.

---

## 🎯 Características

- 📖 Lecciones conceptuales e interactivas.
- 📐 Formulación matemática formal con KaTeX.
- 🧪 Quizzes con retroalimentación inmediata.
- ♿ Escala de tipografía configurable (7 niveles).
- 📶 Funcionamiento 100% offline.

---

## 📥 Descarga (Versión Beta)

1. Descarga el instalador [app-debug.apk](https://github.com/PabloeCancino/uan-apk-topicos-de-matematicas/releases/download/v0.9.0-beta/app-debug.apk) desde la sección de **[Releases](https://github.com/PabloeCancino/uan-apk-topicos-de-matematicas/releases)**.
2. Instala en tu dispositivo Android permitiendo orígenes desconocidos.

---

## 🛠️ Desarrollo Local

```bash
git clone https://github.com/PabloeCancino/uan-apk-topicos-de-matematicas.git
cd uan-apk-topicos-de-matematicas
npm install
npm run dev
```
